# Security policy

Furgaris is used in investigations, so security problems matter more than usual. Thank you for taking the time to report one.

## How to report a vulnerability

**Please don't open a public GitHub issue.** Email **albertplanas@albertplanas.eu** with:

- what the problem is, and where it is (the file, feature or screen);
- how to reproduce it, step by step;
- what an attacker could do with it;
- the Furgaris version (shown in **About & Legal**).

Please use demo data only. Don't send real case data.

## What happens next

- I'll acknowledge your report within **7 days**.
- I'll keep you informed while I work on a fix.
- Once a fix is released, I'll credit you in the changelog, unless you'd rather not be named.

Furgaris is built and maintained by one person alongside a full-time job, so please allow reasonable time for a fix before publishing details.

## Scope

In scope: the Furgaris application (the HTML edition and the Windows desktop app), the standalone verifier, and the release files in this repository.

Out of scope: third-party OSINT websites that Furgaris links to, and AI providers' own services.
